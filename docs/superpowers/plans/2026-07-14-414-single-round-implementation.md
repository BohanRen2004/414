# 4A4 Single-Round Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a complete offline four-player 2-vs-2 single-round 4A4 game that runs in Cocos Creator browser preview and WeChat Mini Game, with a deterministic pure-TypeScript rule core and three basic AIs.

**Architecture:** Keep all rules in immutable, Cocos-free TypeScript modules under `client/assets/scripts/core`; AI and the headless controller consume only public rule interfaces. Cocos components translate touches into `GameAction` values and render returned state/events, but never mutate game truth. Implement in three independently verifiable milestones: rule core, AI/controller, then Cocos presentation/platform acceptance.

**Tech Stack:** Cocos Creator 3.8 LTS, TypeScript, Node.js 20 or newer for local tests, npm lockfile, Vitest, fast-check, Cocos browser preview, WeChat Developer Tools.

## Global Constraints

- Engine is exactly Cocos Creator 3.8 LTS; target WeChat Mini Game and browser preview.
- First release is offline only: no backend, account, login, networking, database, advertising, payment, lobby, or analytics.
- Four fixed seats, fixed teams 0/2 versus 1/3, two complete decks (108 cards), 27 cards per player, one human at seat 0 and three basic AIs.
- `client/assets/scripts/core/**` must never import `cc` or access Cocos nodes.
- Human and AI actions must both pass through `applyAction`; UI must never mutate hands, turns, rankings, or trick state.
- Deal and AI tie-breaking use deterministic seeded PRNG streams; never use `Math.random()` for game decisions.
- Gou-cha is single-card only: another player adds an equal-rank pair for `CHA`; only after that may another player add one equal-rank card for `GOU`; the current holder cannot self-cha or self-gou; straights never start gou-cha.
- Implement with TDD: write a failing test, observe the intended failure, add the smallest implementation, rerun the focused test, then run the relevant suite.
- Do not add event sourcing, a generic rules engine, dependency-injection framework, advanced search AI, card counting, or online synchronization.
- Source design: `docs/superpowers/specs/2026-07-14-414-single-round-design.md`.

```ts
// client/assets/scripts/core/random/prng.ts
export interface RandomSource { nextUint32(): number; nextInt(maxExclusive: number): number; snapshot(): number }

export class XorShift32 implements RandomSource {
  private state: number;
  public constructor(seed: number) { this.state = (seed >>> 0) || 0x6d2b79f5; }
  public nextUint32(): number {
    let x = this.state;
    x ^= x << 13; x ^= x >>> 17; x ^= x << 5;
    this.state = x >>> 0;
    return this.state;
  }
  public nextInt(maxExclusive: number): number {
    if (!Number.isInteger(maxExclusive) || maxExclusive <= 0) throw new RangeError('maxExclusive must be positive');
    return this.nextUint32() % maxExclusive;
  }
  public snapshot(): number { return this.state; }
}

export type RandomStream = 'DEAL' | 'AI';
export function deriveSeed(rootSeed: number, stream: RandomStream): number {
  return (rootSeed ^ (stream === 'DEAL' ? 0xa341316c : 0xc8013ea4)) >>> 0;
}
```

- [ ] **Step 3: Implement the comparison decision order**

```ts
export function beats(candidate: PlayPattern, current: PlayPattern): boolean {
  if (candidate.kind === 'INVALID' || current.kind === 'INVALID') return false;
  if (candidate.kind === 'FOUR_A_FOUR') {
    return current.kind !== 'FOUR_A_FOUR' || (candidate.allHearts && !current.allHearts);
  }
  if (current.kind === 'FOUR_A_FOUR') return false;
  if (candidate.kind === 'JOKER_BOMB') return current.kind !== 'JOKER_BOMB';
  if (current.kind === 'JOKER_BOMB') return false;
  return compareOrdinaryAndBombs(candidate, current);
}

function compareOrdinaryAndBombs(candidate: PlayPattern, current: PlayPattern): boolean {
  if (candidate.kind === 'N_OF_KIND_BOMB') {
    if (current.kind === 'N_OF_KIND_BOMB') {
      return candidate.count > current.count
        || (candidate.count === current.count && candidate.rank > current.rank);
    }
    if (current.kind === 'SINGLE' || current.kind === 'PAIR') return true;
    if (current.kind === 'STRAIGHT' || current.kind === 'DOUBLE_STRAIGHT' || current.kind === 'TRIPLE_STRAIGHT') {
      return candidate.count >= current.multiplicity + 2;
    }
    return false;
  }
  if (current.kind === 'N_OF_KIND_BOMB' || candidate.kind !== current.kind) return false;
  if (candidate.kind === 'SINGLE' && current.kind === 'SINGLE') return candidate.rank > current.rank;
  if (candidate.kind === 'PAIR' && current.kind === 'PAIR') return candidate.rank > current.rank;
  if (
    (candidate.kind === 'STRAIGHT' || candidate.kind === 'DOUBLE_STRAIGHT' || candidate.kind === 'TRIPLE_STRAIGHT')
    && (current.kind === 'STRAIGHT' || current.kind === 'DOUBLE_STRAIGHT' || current.kind === 'TRIPLE_STRAIGHT')
  ) {
    return candidate.multiplicity === current.multiplicity
      && candidate.runLength === current.runLength
      && candidate.high > current.high;
  }
  return false;
}
```

`compareOrdinaryAndBombs` must use count first then rank for two bombs; let count ≥3 beat single/pair/single-straight, count ≥4 beat double-straight, and count ≥5 beat triple-straight; reject ordinary-versus-bomb and all ordinary shape mismatches.
