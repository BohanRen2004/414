# 4A4 微信小游戏

这个目录是微信小游戏工程：横屏，一张全屏 Canvas，规则核心和 AI 与网页版完全相同（`client/assets/scripts`）。

- **单人练习**：你和三家 AI 离线对局，可选一副牌或两副牌。
- **选牌**：点一张牌选中或取消；按住一张牌横着滑过去，一次选中一串（从已选中的牌开始滑则是一串取消），滑回来可以缩回。
- **联机房间**：房主开房间，转发给微信好友，好友点卡片就进房间；开局时空位由 AI 补。发牌、判定和 AI 都在云函数里，每个人只收到自己的手牌。

## 生成代码

`game.js` 和云函数的 `index.js` 都由源码打包生成，不提交到仓库。在仓库根目录运行：

```bash
npm install
npm run build:minigame
```

会生成 `minigame/game.js`（小游戏）和 `minigame/cloudfunctions/room/index.js`（云函数）。改了代码以后重新运行即可。

## 在微信开发者工具里打开

1. 安装[微信开发者工具](https://developers.weixin.qq.com/minigame/dev/devtools/download.html)（Windows / macOS）。
2. 选「小游戏」→「导入项目」，目录选本仓库的 `minigame` 文件夹。
3. AppID：还没有注册时选「测试号」，可以玩单人练习；联机必须用自己的 AppID（测试号不能开云开发）。
4. 点「预览」用手机微信扫码，就能在真机上玩。

## 开通联机（微信云开发）

只需要做一次：

1. **注册 AppID**：在 [mp.weixin.qq.com](https://mp.weixin.qq.com/) 注册「小游戏」（个人主体即可），在「开发管理 → 开发设置」里拿到 AppID，填进开发者工具（或改 `project.config.json` 里的 `appid`）。
2. **开通云开发**：开发者工具顶部点「云开发」，按提示开通并创建一个环境（套餐和费用以控制台显示为准）。只有一个环境时不用改代码；有多个环境时，把要用的环境 ID 填进 `src/cloud-transport.ts` 的 `CLOUD_ENV_ID`，再重新 `npm run build:minigame`。
3. **部署云函数**：在开发者工具左侧找到 `cloudfunctions/room`，右键选「上传并部署：云端安装依赖」。
4. **数据库权限（重要）**：云函数第一次运行时会自动建两个集合 `rooms` 和 `inbox`。之后在「云开发控制台 → 数据库」里设置权限：
   - `rooms`：选「所有用户不可读写」（仅云函数可以读写）。这里存着每局的随机种子和出牌记录，种子能推出所有人的手牌，所以绝不能让客户端读到。
   - `inbox`：选「仅创建者可读写」。每个玩家只有一条，用来通知“该同步了”，不含牌。
5. 在开发者工具里点「创建房间」试一下，再用手机预览，用第二个微信号加入。

## 和朋友玩

- 不必正式上线：上传代码后设为「体验版」，在「成员管理」里把朋友加为体验成员，他们就能打开。
- 房主点「创建房间」→「邀请好友」，把卡片发到群里或私聊；好友点卡片自动进房间。也可以在首页点「加入房间」输入 6 位房间号。
- 在房间里点空位可以换座：1 号和 3 号一队，2 号和 4 号一队（同队坐对面）。房主可以切换一副牌/两副牌，点「开始」，空位由 AI 补。
- 每次轮到你有 60 秒；超时后 AI 替你出牌（托管），点「取消托管」接回。中途离开也由 AI 接着打完。
- 退出微信再回来，会自动回到原来的房间。
- 一局结束后房主点「回到房间」，可以换座、换人再开下一局。

## 隐私设计

- 服务器只存「种子 + 出牌记录」，每次请求按记录重放规则得到当前局面；发给每个人的只有他那个座位能看到的画面：别人的手牌只有张数，种子在一局结束后才给。
- 勾岔询问保密：有人被问要不要岔/勾时，其他人看不到，也不会收到通知，看起来就像出单牌的人还在想。
- 能做的动作由云函数按微信身份（openid）校验，客户端不能替别人出牌。

## 目录

- `src/game.ts`：微信入口，创建画布、处理触摸、分享卡片、启动参数里的房间号。
- `src/app.ts`：首页、单人练习、房间和联机牌桌的交互。
- `src/online-session.ts`：联机客户端：请求云函数、按顺序播放自己座位的画面、实时推送失效时轮询。
- `src/cloud-transport.ts`：`wx.cloud` 调用云函数、监听自己的 inbox。
- `src/screen.ts`：把对局状态整理成要画的内容（只含你自己能看到的信息）。
- `src/render.ts`：Canvas 绘制和点击区域。
- `cloudfunctions/room/`：云函数（`index.js` 由 `../server` 打包生成）。
- `game.json`、`project.config.json`：小游戏配置（横屏、云函数目录、打包时忽略 `src`）。

服务端源码在仓库根目录的 `server/`：`room/engine.ts`（房间和对局规则）、`room/handler.ts`（请求校验、并发写入重试）、`cloud/room-function.ts`（云数据库适配）。
